# Seasons

A small React app that detects your location and tells you the current season. Built with [Vite](https://vite.dev/) and [React](https://react.dev/).

> Note: the app uses the browser Geolocation API, which only works over `https://` or on `localhost`.

## Getting Started

Install dependencies:

```sh
npm install
```

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Runs the app in development mode with hot module replacement.<br />
Open the URL printed in the terminal (default [http://localhost:5173](http://localhost:5173)) to view it in the browser.

`npm start` is an alias for the same command.

### `npm run build`

Builds the app for production to the `build` folder.<br />
The output is minified and assets include content hashes for cache-busting.

### `npm run preview`

Serves the production build from `build/` locally so you can verify it before deploying.
